# One Life

Site vitrine de One Life : sites web et outils Python pour les petits commerces, au Maroc.

Site en ligne : https://one-life-camara-website.vercel.app/

## Fichiers

- `index.html` : la page (accueil, services, projets, à propos, contact)
- `style.css` : la mise en forme
- `script.js` : le formulaire de contact
- `imageaa.png` : image d'arrière-plan de l'accueil

## Technologies

HTML, CSS, JavaScript. Hébergé sur Vercel.

## Formulaire de contact

1. Créer un formulaire gratuit sur Formspree.
2. Copier son adresse dans `FORM_ENDPOINT`, en haut de `script.js`.
3. Tester avec une autre adresse mail.

Tant que `FORM_ENDPOINT` est vide, le formulaire affiche un message qui renvoie vers WhatsApp.

## Tester en local

Ouvrir le dossier dans VS Code et lancer l'extension Live Server.
